# Qadam — персональный маршрут поступления

> **Qadam** (қазақша «қадам» — шаг) — AI-сервис, который превращает профиль и цель абитуриента
> в понятный маршрут: куда поступать, почему этот вариант подходит и что делать следующим шагом.
>
> 🇰🇿 Қазақша · 🇷🇺 Русский · 🇬🇧 English — переключатель языка в шапке сайта.

Проект создан для **LOCUS Startup Hackathon 2026, Кейс 02 «Персональный маршрут поступления»**
.

---

## 1. Задача

Абитуриенту нужен маршрут, а не ещё один список университетов. Поступление состоит из десятков
решений — направление, университет, экзамены, документы, дедлайны, — и информация разрознена.
По кейсу требовалось создать самостоятельный AI-сервис с сильным пользовательским путём:
от короткой анкеты до рекомендаций и пошагового плана действий (7 обязательных этапов).

## 2. Решение

**Qadam** проводит пользователя по маршруту из 7 этапов кейса и добавляет сервисные экраны:

1. **Вход** (`/`) — ценность сервиса и ожидаемый результат за 3 минуты.
2. **Профиль** (`/profile`) — анкета из 7 подшагов: класс, город, **единый поиск предметов
   и желаемых специальностей**, успеваемость, бюджет (с опцией «не ограничен»), формат
   обучения, экзамены со слайдерами оценок (ЕНТ 50–140, IELTS 4.0–9.0, SAT 400–1600),
   приоритеты и финальная проверка ответов.
3. **Диагностика** (`/diagnostics`) — резюме профиля: цель, сильные стороны, ограничения.
4. **Рекомендации** (`/results`) — минимум 3 программы с объяснением «почему подходит»,
   кольцом совместимости, честными пометками источников и кнопкой избранного.
5. **Сравнение** (`/compare`) — таблица 2–3 вариантов по стоимости, проходному баллу ЕНТ,
   грантам, предметам, языкам, городу и общежитию (на мобильных — карточки).
6. **Roadmap** (`/roadmap`) — персональный план: экзамены, документы, академические шаги,
   активности; каждый пункт с объяснением «зачем», периодом и источником + **экспорт в PDF**
   (страница `/roadmap/print`, печать браузера).
7. **Следующее действие** — один выделенный ближайший шаг на каждом экране после профиля.

Сверх кейса: **календарь дедлайнов** (`/calendar`), **подбор стипендий и грантов** (`/scholarships`),
**избранное** (`/favorites`), **«думающий» анализ** перед выдачей — стадированные фазы с честным
прогрессом и всплывающими мини-квизами, уточняющими профиль, и **«Спроси ИИ»** — ответы на вопросы
о своих вариантах, плане, сайте и поступлении в КЗ с учётом профиля (OpenRouter, free-tier модель,
скоуп строго ограничен темами образования).

## 3. Стек

- **Next.js 16** (App Router, Turbopack) + **React 19** + **TypeScript**
- **Tailwind CSS 4** — авторская дизайн-система (палитра pine/moss/clay/paper)
- Чистые TypeScript-движки рекомендаций, диагностики и roadmap (rule-based, без БД)
- **OpenRouter API** (free-tier LLM) для блока «Спроси ИИ»
- Персистентность: `localStorage` (профиль, избранное, XP) — без регистрации

## 4. Архитектура

```
src/
├── app/                    # маршруты (App Router)
│   ├── page.tsx            # этап 1: вход
│   ├── profile/            # этап 2: анкета (7 подшагов, поиск интересов)
│   ├── diagnostics/        # этап 3: резюме профиля + «Спроси ИИ»
│   ├── results/            # этап 4: «думающий» анализ + рекомендации + ИИ
│   ├── compare/            # этап 5: сравнение (таблица + мобильные карточки)
│   ├── roadmap/            # этапы 6–7: план + следующее действие
│   │   └── print/          # версия плана для печати/экспорта в PDF
│   ├── favorites/          # избранное
│   ├── calendar/           # календарь дедлайнов
│   ├── scholarships/       # стипендии и гранты
│   └── api/ask/route.ts    # прокси к OpenRouter (ключ только на сервере)
├── components/             # JourneyLayout, Stepper, AnalysisOverlay, AskAiPanel, LogoMark…
├── context/                # ProfileContext (localStorage, hydration-guard)
├── i18n/                   # словари RU/KK/EN, LanguageContext, GamificationContext (XP)
├── lib/
│   ├── engine/             # recommend.ts, diagnostics.ts, roadmap.ts — чистые функции
│   ├── constants.ts        # этапы, справочники (17 предметов, 15 городов), форматтеры
│   └── data.ts             # загрузка JSON-данных вузов/программ
├── data/                   # universities.json (31 вуз, 13 городов), programs.json (90 программ)
└── types.ts                # доменные типы
```

**Ключевые решения:**

- **Экраны — чистые проекции профиля.** Любое изменение анкеты мгновенно пересчитывает
  рекомендации, диагностику и план (требование жюри «изменил вводные → изменился результат»).
- **Rule-based движок + объяснения.** Скоринг: желаемая специальность +14 / предметы 30 /
  бюджет 25 / академика 20 / формат 15 / язык 10 / рейтинг вуза до +5 + приоритеты пользователя
  до ±12. Каждое слагаемое порождает человеческое объяснение «почему подходит» или предупреждение.
- **Три языка** едины для UI и для строк движков: объяснения, план и диагностика
  локализованы (RU / KZ / EN).
- **ИИ изолирован.** Ключ OpenRouter живёт только в переменной окружения на сервере;
  клиент общается с `/api/ask`. Есть fallback на список free-моделей.

## 5. Инструкция запуска

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшен-сборка:

```bash
npm run build && npm start
```

**Блок «Спроси ИИ»** требует ключ OpenRouter:

1. Получите бесплатный ключ на openrouter.ai.
2. Скопируйте `.env.example` в `.env.local` и вставьте свой ключ:
   ```
   OPENROUTER_API_KEY=sk-or-v1-...
   OPENROUTER_MODEL=z-ai/glm-5.2:free   # опционально
   ```
3. Перезапустите dev-сервер. Без ключа всё приложение работает, раздел ИИ
   честно сообщает о недоступности.

## 6. Тестовый сценарий (для жюри)

1. Откройте сайт → нажмите «Пройти анкету».
2. Пройдите 7 подшагов анкеты (например: 11 класс, Алматы, в поиске введите «IT» →
   выберите «Информатика» и майор «Компьютерные науки», бюджет 1 000 000 ₸,
   ЕНТ-прогноз 95, приоритет «стоимость»).
3. На экране «Диагностика» проверьте резюме цели, сильных сторон и ограничений.
4. «Рекомендации» — минимум 3 варианта; раскройте «почему подходит»;
   добавьте один вариант в избранное и два в сравнение.
5. В блоке **«Спроси ИИ»** задайте вопрос из чипов-подсказок (например,
   «Какой балл ЕНТ мне нужен на грант?»).
6. «Сравнение» — проверьте таблицу по 8 параметрам и бейдж «вы проходите\*».
7. «Мой план» — отметьте 2–3 шага: прогресс-бар растёт, XP увеличивается,
   «Следующий шаг» переключается на незавершённый пункт. Нажмите «Экспорт в PDF» —
   откроется печатная версия плана.
8. **Ключевая проверка:** вернитесь в профиль, измените бюджет или прогноз ЕНТ —
   рекомендации и план пересчитываются мгновенно (при повторном заходе на рекомендации
   показывается стадированный «думающий» анализ с мини-квизами).
9. Переключите язык RU → KZ → EN в шапке — интерфейс и объяснения меняются полностью.
10. Сузьте экран до мобильного — основной путь работает: степпер сжимается,
    сравнение превращается в карточки, кнопки и чипы имеют увеличенные зоны нажатия.

## 9. AI / API

- **OpenRouter** (`https://openrouter.ai/api/v1/chat/completions`) — free-tier модели:
  основной `z-ai/glm-5.2:free`, fallback `google/gemma-4-31b-it:free`,
  `inclusionai/ling-3.0-flash-vl:free`. Используется только в `/api/ask`
  (блок «Спроси ИИ» на экранах диагностики, рекомендаций и плана).
- Системный промпт ограничивает ассистента двумя способами: **скоуп** — отвечать только
  про поступление, образование, экзамены, гранты и сам сайт Qadam (остальное — вежливый
  отказ и возврат к теме), и **качество** — отвечать по контексту профиля, не выдумывать
  дедлайны/цены, не гарантировать поступление, отвечать на языке вопроса, до 120 слов.
- **Остальная логика продукта — детерминированный rule-based код** (скоринг, план, календарь),
  поэтому рекомендации воспроизводимы и объяснимы без LLM.

## 10. Готовые компоненты (раскрытие)

- **Создано в период хакатона:** вся логика кейса — движки рекомендаций/диагностики/roadmap,
  анкета, экраны, дизайн-система (палитра pine/clay/paper), i18n, геймификация, `/api/ask`.
- **Готовые универсальные компоненты:** Tailwind CSS 4 (utility-стили), шрифт
  [Manrope](https://fonts.google.com/specimen/Manrope) (SIL OFL) через `next/font`,
  сгенерированные иконка и OpenGraph-картинка (`next/og`).
- **Заранее созданных авторских компонентов не используется** — шаблонов, платных
  UI-kit'ов или дизайн-систем сторонних авторов в проекте нет.

## 11. Ограничения

- Проходные баллы, количество грантов и сроки подачи — **демонстрационные данные**;
  UI помечает каждый такой факт бейджем «demo» и ссылкой на официальный источник, где возможно.
  Решение осознанное: данные о баллах меняются ежегодно, и для прототипа честнее пометка
  «demo», чем мнимая точность.
- География кейса — Казахстан (31 вуз в 13 городах, 90 программ); зарубежные вузы
  не моделируются (только сценарий «КЗ + за рубеж» в плане).
- Каталог не претендует на полноту: включены крупные вузы и популярные специальности;
  расширение — редактированием JSON-файлов без изменения кода.
- «Спроси ИИ» зависит от доступности free-tier моделей OpenRouter: возможен rate-limit,
  при ошибке показывается честное сообщение и советы повторить позже.
- Профиль, избранное и XP хранятся в `localStorage` браузера — синхронизации между
  устройствами нет (осознанное упрощение: полный путь работает без backend).
- Сервис не гарантирует поступление и не заменяет официальные источники — он объясняет
  маршрут и показывает, что проверять.
