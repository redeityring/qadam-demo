# Qadam — жеке түсу маршруты (қазақша)

> **Qadam** («қадам» — шаг) — абитуриенттің профилі мен мақсатын түсінікті маршрутқа айналдыратын
> AI-сервис: қайда түсуге, неге бұл нұсқа келеді және келесі қадам не істеу керек.
>
> Толық құжаттама: [README.md](./README.md) (орысша). Интерфейс тілдері: Қазақша / Русский / English.

## Міндет
Түсуде ондаған шешім бар — бағыт, университет, емтихандар, құжаттар, дедлайндар. Ақпарат шашыраңқы.
Кейс: қысқа сауалнамадан ұсыныстар мен қадамдық жоспарға дейінгі тұтас AI-сервис жасау
(міндетті 7 кезең, LOCUS Startup Hackathon 2026, 02-кейс).

## Шешім
Qadam пайдаланушыны 7 кезеңнен өткізеді: кіру → профиль (7 қадамдық сауалнама) → диагностика →
ұсыныстар («неге келеді» түсіндірмесімен) → салыстыру → жоспар (roadmap) → келесі қадам.
Қосымша: дедлайн күнтізбесі, стипендиялар мен гранттар, таңдамалы және «ЖИ-ден сұра» бөлімі
(OpenRouter free-модельдері).

## Технологиялар
Next.js 16 + React 19 + TypeScript, Tailwind CSS 4, rule-based ұсыныс қозғалтқыштары,
OpenRouter API (тек серверде кілт), деректер localStorage-те.

## Архитектура
Экрандар — профильдің таза проекциялары: кез келген өзгеріс ұсыныстар мен жоспарды бірден
қайта есептейді. Скоринг: пәндер 30 / бюджет 25 / академика 20 / формат 15 / тіл 10 +
пайдаланушы басымдықтары ±12. Әр салмақ — адам тіліндегі түсіндірме.

## Іске қосу
```bash
npm install
npm run dev   # http://localhost:3000
```
«ЖИ-ден сұра» үшін `.env.local` файлына `OPENROUTER_API_KEY` қосыңыз (қараңыз: README.md).

## Тест жоспары
Сауалнаманы толтырыңыз → диагностика → ұсыныстар (неге келетінін тексеріңіз) → екеуін салыстырыңыз →
жоспардан қадам белгілеңіз (XP өседі) → профильдегі бюджет/ЖБТ-ны өзгертіңіз (нәтиже бірден өзгереді) →
тілді RU/KZ/EN ауыстырыңыз → мобильді көріністі тексеріңіз.

## Рөлдер, дереккөздер, шектеулер
Команда рөлдері, дереккөздер (entec.gov.kz, e.gov.kz, ielts.org, университет сайттары),
AI/API сипаттамасы және шектеулер толық нұсқада: [README.md](./README.md).
Өту балдары мен грант саны — **демо-деректер (2025)**, интерфейсте арнайы белгіленген.
